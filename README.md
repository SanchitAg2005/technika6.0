# technika6.0 — Technika 6.0 Event Website

Static marketing/event website for Technika 6.0.

## What This Repository Is

This repository contains the front-end website for the Technika 6.0 event — a static, animated marketing site built with vanilla JavaScript and GSAP for animations.

It is **not** the registration or management platform.

## Technology

- Vite (build tool)
- Vanilla JavaScript
- GSAP (animations)

## Project Status

This is a **previous/archived** iteration. The active Technika registration system is maintained separately.
